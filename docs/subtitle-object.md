# 合成フォント字幕オブジェクト

`合成フォント字幕`は、PSDToolKit2の`セリフ準備@PSDToolKit`から字幕テキストを取得し、
合成フォントプロファイルを適用して表示する専用オブジェクトである。

## 配置

`合成フォント字幕.object`はAviUtl2のアプリケーションデータにある`Alias`へ配置する。
本プロジェクトでは`au2 develop`と`au2 release`の成果物へ自動的に含める。

## 使い方

1. PSDToolKit2の`最初に置くやつ@PSDToolKit`を上のレイヤーへ配置する。
2. `セリフ準備@PSDToolKit`を配置し、キャラクターIDとテキストを設定する。
3. その下のレイヤーへ`合成フォント字幕`を追加する。
4. `合成フォント字幕`のテキスト欄にある`settings`を編集する。

```lua
local settings = {
    id = "ずんだもん",
    profile = "subtitle",
}
```

`id`にはセリフ準備のキャラクターID、または`"L3"`のようなレイヤー指定を設定する。
`profile`には合成フォントエディターで保存したプロファイル名を設定する。

文字サイズ、字間、行間、文字色、装飾、揃えは通常のテキストオブジェクトと同じ設定を使う。
字間と文字サイズは`compositefont.decorate`へ渡され、プロファイル側の字送りと
ベースライン補正の基準になる。

## 実装上の理由

PSDToolKit2の`mes()`はセリフ準備の文字列を戻り値として公開せず、テキストオブジェクト内で
`obj.mes()`へ直接渡す。AviUtl2の`obj.mes()`もテキストオブジェクト内専用である。
このため`.obj2`のカスタムオブジェクトではなく、Lua制御文字を格納した専用の
テキスト・オブジェクトエイリアスとして実装している。
