# 合成フォントテキストオブジェクト

`合成フォントテキスト`は、AviUtl2標準のテキストオブジェクトから任意の本文へ
合成フォントプロファイルを適用するエイリアスである。PSDToolKit2は必要ない。

## 使い方

1. オブジェクト追加メニューから`合成フォントテキスト`を追加する。
2. テキスト欄の`settings`にプロファイル名と本文を設定する。

```lua
local settings = {
    profile = "subtitle",
    text = [=[国LINE123国]=],
}
```

`text`はLuaの長い文字列なので、通常の引用符や改行をそのまま入力できる。
本文に文字列`]=]`を含める場合は、区切りを`[==[`と`]==]`へ変更する。

フォントサイズ、字間、行間、文字色、装飾、揃えなどは通常のテキストオブジェクトと同じ設定を使う。
サイズと字間はプロファイル側のベースライン補正と字送り補正の基準にもなる。

## 既存テキストオブジェクトから直接呼ぶ

新しいエイリアスを使わず、既存のテキストオブジェクトのテキスト欄へ次のLua制御文字を
記述しても同じ処理を呼び出せる。

```lua
<?
local text = [=[任意のテキスト ABC123]=]
local compositefont = obj.module("compositefont")
local _, size, _, _, _, _, _, spacing = obj.getfont()
obj.mes(compositefont.decorate(text, "subtitle", size, spacing))
?>
```

`decorate`は既存のAviUtl2制御文字との衝突を避けるため、本文に半角`<`が含まれる場合は
加工せずそのまま返す。
