# anm2仕様

「描画@comfont」は自由入力のプロファイル名を持ち、次の短い処理を行います。

```lua
obj.effect("Comfont native text")
```

aux2に登録された非表示フィルタが、標準テキストの保存本文と設定を読み、選択プロファイルで一時文字列を作って標準「テキスト」入力へ渡します。AviUtl2のDirectWrite描画を使い、プロジェクトの本文は書き換えません。

## 対象外

- 未連携のLua本文、未対応・不正な制御タグ、複数の標準「テキスト」入力は変更せず通常描画へ戻します。
- プロファイルが見つからない場合や入力を安全に読めない場合は、装飾を適用しません。
- API 17の本文内Lua連携は、生成元が装飾前の全文を `capture_text` へ明示登録した場合に適用します。保存本文全体が1つのLuaブロックで、オブジェクトID・フレーム・原文が一致すれば、aux2が通常文字とSVG絵文字を合成します。複数ブロックやブロック外の文字は対象外です。[Lua API](lua-api.md)を参照してください。
- 通常描画のリガチャはAviUtl2標準に従います。ZWNJは挿入しません。

## SVG絵文字の自動合成

API 18の生成本文APIは、生成元効果・コードを添えた明示登録を受け取り、現在のコード・保存本文・ID・フレーム・効果順序を照合します。実行済みの本文内Luaから文字列を自動取得する機能はありません。[API仕様](lua-api.md#生成本文の一時連携)を参照してください。

通常経路では、対応するSVG絵文字とキーキャップをラスタライズし、AviUtl2が描いた通常文字へ合成します。キーキャップは下位で選んだフォントがCOLR/CPALや単色の字形でも対象です。保存本文を変更せず、追加フィルタや別aux2も必要ありません。

設定プレビューとの対応形式の違い、国旗・肌色・ZWJ、縦横倍率、対象条件、上限、Comfont Emoji Markerについては[絵文字の設定と制約](emoji.md)を参照してください。内部の合成手順は[描画経路](native-text-path.md#svg絵文字の合成)に記載しています。

## リガチャを強制ON（試験機能）

API 17・18で明示収集した本文は、このON/OFFにかかわらず通常文字＋絵文字の部分合成を使います。以下の全体画像化には入りません。

初期値はOFFです。OFFでは通常文字にAviUtl2の標準「テキスト」を使い、対応するSVG絵文字とキーキャップは上記の自動合成を使います。OpenType機能は標準描画とフォントに従います。プロファイル内のリガチャON/OFFは設定プレビュー専用です。

ONではaux2が保存本文とプロファイルを読み、**一部のグリフだけではなくオブジェクト全体**をDirectWriteで組版します。`liga` / `clig` / `dlig` / `hlig` を各書式範囲に明示的に有効化し、プロファイル内の解除指定より優先します。ただし、フォントが持たない合字は生成できず、フォント・書式が切り替わる境界をまたぐ合字も保証しません。本文やプロファイルは書き換えません。

ONの対象は標準テキスト入力が1つの静的なオブジェクトだけです。Lua本文、未対応の制御タグ、タブ、64 KiBを超える本文、標準文字以外の装飾（縁取り・影）、非ゼロの表示速度、文字毎の個別オブジェクト、自動スクロール、移動座標上への表示には適用しません。フォントの欠落・カラーフォント・不正な設定、描画や画素転送の失敗時も標準描画へ戻ります。文字サイズは1～4096で、生成画像は一辺8192ピクセル、総1677万画素までです。**画面通知なく標準描画へ戻るため、ONでも合字が見えない場合があります。**

ONのときだけ表示される「アンチエイリアス」は「標準」（Natural）、「滑らか」（Natural Symmetric）、「なし」（Aliased）から選択します。前二者の差は大きい文字では小さくなります。描画結果はBGRA画像としてオブジェクトへ渡すため、AviUtl2の標準描画と輪郭・字間・配置が一致する保証はありません。縁取り・影などを画像経路で再現しようとはせず、標準描画へ戻します。

au2の描画経路はv2.1.14で実証した `FILTER_PROC_VIDEO::exec_effect` を使います。従って対応ホストはAviUtl2 v2.1.14以降です。詳しい制約と実機確認状況は[描画経路の資料](native-text-path.md)を参照してください。

過去の可逆Luaラッパーは、本文欄の「合成フォント → 元の本文に戻す」メニューで明示した場合だけ復元します。新しい本文書き換え処理はありません。
