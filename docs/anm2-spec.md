# anm2仕様

## 入力と描画

`@comfont.anm2`に「パイプ@comfont」と「描画@comfont」を収録します。パイプは設定欄なしの収集専用で、原文または明示連携済みの本文をaux2へ渡します。スクリプト入力欄・変数名欄・本文加工・Lua実行は持ちません。共有変数`text`の無条件取得や他スクリプトのローカル変数取得も行いません。

描画は`comfont::プロファイル`の1行の自由入力欄（初期値`default`、完全一致）と、`comfont::リガチャを強制解除`のチェック（初期値OFF）を持ちます。専用の適用チェックはありません。効果の無効化・削除で通常表示へ戻します。

```text
標準テキストの原文 / スクリプト生成後の本文
  → パイプ（登録済み本文を確認、なければ静的原文を収集）
  → generated_text（登録済み本文を優先、なければ原文をdecode_text）
  + プロファイル名 + リガチャ解除ON/OFF
  → decorate（制御文字列を生成）
  → render_decorated（aux2で画像化）
  → obj.putpixeldata（表示画像を差し替え）
```

テキストボックスには原文を保持し、生成した制御文字を書き戻しません。オブジェクトにはプロファイル名とリガチャ解除ON/OFFを保存します。描画側にはプロファイルを渡さず、設定を二重適用しません。

標準テキストではSDKの`obj.load("text", ...)`を使えないため、画像差し替えを使用します。anm2は`obj.module("compositefont")`でaux2へ自動接続し、描画はAPI 14以降、パイプはAPI 15以降を要求します。

### スクリプト制御との連携

公開APIでは実行後本文を取得できないため、生成スクリプトには[共通スニペット](../readme.md#スクリプト制御との連携)を手動で追加します。後段のanm2がオブジェクトID・フレーム・保存原文で照合し、登録済み本文をdecorateへ渡します。スクリプト制御では生成元のコードと有効状態も照合します。登録済み本文はalias復号しません。Lua原文をanm2から再実行せず、未登録のLua本文は元画像を維持します。[引数・空文字と複数表示の扱い](lua-api.md#生成本文の連携)。

同梱字幕オブジェクトはPSDToolKitの`modifier`で生成本文を登録し、後段の描画@comfontで装飾します。セリフがない場合は空文字を登録します。通常表示用の経過済み先頭waitタグは装飾経路へ渡しません。字幕の表示速度は0専用で、本文中の待機・速度制御など未対応タグは通常表示になります。

## 更新と優先順位

描画対象の本文・プロファイル内容・基準サイズ・字間・リガチャ解除ON/OFFなどをキーに結果をキャッシュします。生成本文の登録は最大64件 / 4 MiB、装飾文字列は最大16件 / 4 MiB、描画画像は最大16件 / 64 MiBです。プロファイルファイルは描画時に約1秒間隔で確認します。保存時にanm2を生成・上書きしません。

カスタム範囲優先、重複は上から最初の一致を採用します。原文の対応済み書式タグは属性ごとにプロファイルより優先します。生成文字列の基本書式と`gw / tw / th / p+0,y`、各リセットを描画側で解釈します。

装飾生成は書記素単位です。範囲・分類は元の書記素の先頭文字で判定し、フォント・補正をまとまり全体へ適用します。候補の字形確認も正規化後の書記素全体で行い、結合記号・ヴィラーマ・結合子の途中へタグを挿入しません。

描画用文字列のみNFC正規化し、段落全体をDirectWriteでレイアウトします。合字・結合記号・カーニング・双方向表示の字形と位置を維持したまま、色・サイズ・字送り・ベースライン・縦横比率を反映します。段落方向は最初の強い方向文字から決めます。プレビューも同じエンジンを使います。

設定画面の「リガチャ / 有効」はONが有効（初期ON）、OFFが強制解除です。保存形式は互換性を保ち、各フォント設定の`disable_ligatures`へ反転して保存します（省略時false＝有効）。その範囲にだけ解除を適用し、anm2のチェックONは全範囲を解除します。フォント名が空でも解除設定は有効です。生成文字列の`<cf_liga0> / <cf_liga>`はaux2描画専用で、本文には保存しません。

リガチャ解除ONではOpenTypeの合字を無効化し、描画用文字列の文字間へ非結合文字（ZWNJ）を挿入して必須結合も抑止します。改行・空白・保存本文は変更しません。接続形や結合記号、カーニング・字間も変わるため、通常の多言語表示にはOFFを使います。入力済みの単一の合字文字（例：U+FB03）は分解しません。プロファイルに装飾がなくてもONは有効です。設定画面のプレビューは範囲別の解除設定を反映します。オブジェクト単位のanm2チェックはプレビューには適用しません。

## 制限と通常表示

対象は横書き・標準文字装飾・静止本文、9種類の揃え、色、太字・斜体です。空欄・存在しない名前・全範囲削除（解除OFF時）・aux2未接続・未対応設定・処理失敗時は元画像を維持します。

言語範囲による除外はありません。文字組みの対応はWindowsのDirectWriteと使用フォントに依存し、ホストとの完全一致は保証しません。縦書き、影・縁取り・取り消し線、表示速度、個別文字、スクロール、移動経路、未連携のLua本文・未対応タグ、カラーフォントは対象外です。必要な字形が見つからない場合も元画像を維持します。

原文・生成文字列は64 KiB、サイズは1～512、画像は4096×4096まで。anm2は本文を生成するスクリプト制御 → パイプ → 描画の順で、他の画像加工フィルターより前に配置します。

## 互換性と配布

旧ID選択は参照せず、更新後に名前を入力します。空欄を自動でdefaultに置き換えません。旧チェックボックス値は参照しません。旧Lua APIは互換用に維持します。

0.3.1では旧「合成フォント.anm2」を配布から除外します。旧効果を使うオブジェクトは「描画@comfont」へ置き換え、プロファイルを指定します。

配布はaux2・「@comfont.anm2」・PSDToolKit用の「合成フォント字幕.object」・ライセンス。字幕オブジェクトはAliasへ配置します。その他の旧object・検証用obj2は含めません。[実機確認の残項目](validation.md)は検証状況にまとめています。
