# 合成フォント.anm2 仕様（v0.2.0 / API 11）

この版のanm2連携は以下の契約で固定する。Rust製aux2はaviutl2-rsを使用し、anm2はLuaで実装する。実装: [anm2](../scripts/合成フォント.anm2)、[選択肢生成](../crates/editor-plugin/src/profile_selector.rs)、[モジュール](../crates/module-plugin/src/lib.rs)。

## 適用方法と保存本文

標準テキストにアニメーション効果「合成フォント」を1つ追加する。anm2はobj.module("compositefont")でaux2内の描画モジュールへ自動接続する。接続のための本文ラッパー、事前適用、専用objectは不要。

anm2はobj.getvalueで元の本文・フォント・サイズ・字間・行間・色・整列・B/Iを読み、module.render_textで生成したBGRA画像をobj.putpixeldataへ同期アップロードする。整列に合わせて効果処理中のobj.cx/cyを設定する。保存される本文、標準テキストの設定値、プロジェクトのオブジェクト構成は変更しない。

効果は他の画像加工フィルターより前へ置く。先行フィルターの加工画像は再描画によって失われる。同名効果を複数追加する構成は未対応で、保存ラベルの取得は最初の有効な同名効果を参照する。

## プロファイル選択

| 値・項目 | 契約 |
|---|---|
| プロファイル選択 | anm2のselectプルダウン。初期値はdefault |
| 無装飾 | ID -1。aux2の描画を呼び出さず元画像を維持 |
| default | ID 0。名前とプロファイル自体の削除は不可。範囲は全削除可能 |
| その他 | UTF-8の名前からFNV-1aで生成した正の31bit ID。並べ替えても選択を維持 |
| 旧版のプロファイル指定 | 折りたたみの文字列欄。空欄ならプルダウンを使用。非空なら旧名を優先。ただし無装飾が最優先 |

表示ラベルではカンマ・等号・コロン・バックスラッシュを全角へ置き換え、制御文字を空白へ置き換える。生成時にID競合・表示名競合（予約名「無装飾」を含む）を拒否する。

描画時はIDに一致するプロファイルが1件だけ存在し、保存された表示ラベルとも一致することを確認する。不一致・削除・改名・存在しない旧名では元画像を維持し、別プロファイルやdefaultへ自動で切り替えない。改名は新しい選択肢として扱うため、再起動後に各オブジェクトで選び直す。同じ名前を再作成した場合は同じIDとして扱う。

## 保存と更新

エディターの保存時にprofiles.jsonを検証・保存し、Script/合成フォント.anm2のselect定義を一覧順で生成する。AviUtl2のプルダウン定義は静的で、追加・削除・改名・並べ替えの反映には再起動が必要。Luaのprofile_names()を実行してもプルダウンを動的には更新しない。

既存プロファイルのフォント・補正値の変更は再起動不要で、モジュールが約1秒間隔でファイル変更を確認する。UIの「適用」は編集モデルとプレビューだけを更新し、動画側への反映には「保存」が必要。anm2生成に失敗した場合は、JSON保存済みであることと選択肢更新失敗を表示する。

## 対応範囲と元画像への復帰

横書き、標準文字装飾、9種類の文字揃え、色、太字・斜体を対象にする。本体と共通のカスタムUnicode範囲・文字分類・グリフ判定・フォールバック・補正値を用いる。カスタム範囲が優先、重複時は上から最初に一致した範囲を採用、全範囲削除は無装飾。

縦書き、影・縁取り・取り消し線、表示速度、文字毎の個別オブジェクト、スクロール、移動経路、Lua本文、未対応タグ、結合文字・複雑な文字組み・絵文字シーケンスは元画像を維持する。対応済み基本書式タグはプロファイルより属性ごとに優先する。字形単位の描画であり、ホストのカーニング・合字・全レイアウトの完全再現は対象外。

本文は64 KiB以内、基準サイズ1～512、画像4096×4096以内。未対応設定、不正な値、描画失敗、aux2未接続・API 11未満、無装飾では元画像を維持する。効果の無効化・削除でもホストの元描画へ戻る。

画像は所有権付きuserdataで同期アップロード完了まで保持する。本文・元の設定・プロファイル全体をキーに最大16件／64 MiBをキャッシュし、変更のない動画フレームで再描画しない。エディターUIの更新は動画フレーム処理から独立させる。

## 検証と採用範囲

AviUtl2 v2.1.2で、追加だけの接続、プルダウン、プロジェクト保存本文の保持、無装飾・効果無効化での復帰を確認済み。ID・ラベル・削除・並べ替えは自動検証も行う。[検証記録](validation.md)に実機確認済み／未確認を分けて記載する。動画書き出しと異なるDPIのモニター間移動は正式採用前の確認項目として残す。
