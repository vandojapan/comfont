# 合成フォントエディタ

AviUtl2の`設定` → `プラグイン設定` → `合成フォント…`から開く。

## 操作

1. 上部のプロファイル欄でプロファイルを選択する。
2. 表から文字種を選択する。
3. フォント、サイズ、ベースライン、字送り、垂直比率、水平比率を入力して`適用`する。
4. `保存`または`OK`でプロファイルを保存する。

数値の単位は%。サイズ・垂直比率・水平比率の`100`は等倍、ベースラインと字送りの`0`は補正なしを表す。
`新規…`で中立設定のプロファイルを追加でき、上部のプロファイル名を直接編集して保存できる。

文字種一覧の下にある`＋`を押すと、最後にフォーカスした行と同じ文字種の追加行を作成する。
例えば漢字の1行目を選んで追加し、1行目をStd、2行目をPr6にすると、Stdの収録範囲を優先し
不足分だけPr6で補える。かな、カナ、数字、記号、欧文、その他も同じように複数行を設定できる。
同じ文字種は一覧の上から順にグリフを確認する。各文字種の先頭行は必須で削除できないが、追加行は
選択して`－`を押すと削除できる。

文字種一覧は`Ctrl`または`Shift`を押しながらクリックすると複数行を選択できる。最後にフォーカス
した行の値が編集欄へ表示され、`適用`、`保存`、`OK`または数値欄のホイール操作で、編集欄の
フォントと補正値一式を選択中の全行へ反映する。`－`は選択中の追加行をまとめて削除する。

下部のサンプルは、文字分類ごとのフォント、サイズ、ベースライン、字送り、垂直・水平比率を混在表示する。
`特殊文字…`では文脈共有文字の固定分類を確認できる。

## 保存と反映

プロファイルはAviUtl2のアプリケーションデータにある
`compositefont/profiles.json`へ保存する。`schema_version`は現在`1`。

module-pluginは同じファイルの更新を1秒間隔で確認する。エディタで保存した変更は、AviUtl2を
再起動しなくても次回の`compositefont.resolve`呼び出しから反映される。

保存される「合成フォント名」はフォントファミリーではなく、文字分類ルールをまとめた
プロファイル名である。保存してもAviUtl2標準テキストのフォント一覧には追加されない。
字幕側から`compositefont.decorate(text, profile, size, spacing)`を呼び出し、`profile`に
この名前を指定して利用する。

## 追加フォント

AviUtl2のアプリケーションデータにある`compositefont/fonts`へTTF/OTF/TTC/OTCを配置する。
通常構成では`C:\ProgramData\aviutl2\compositefont\fonts`、ポータブル構成では本体横の
`data\compositefont\fonts`になる。`保存`を押すと、新しいファイルだけをAviUtl2公式の
`Font\compositefont`へコピーする。同名ファイルは上書きしない。配置した実フォントの使用には
AviUtl2の再起動が必要になる。このビルドからFontManagerの登録処理は呼び出さず、合成プロファイル名を
標準フォント一覧へ追加することもない。

合成フォントエディターのプルダウンは、開くたびにFontManagerが現在公開しているフォント名を
読み取るだけで、登録内容は変更しない。
