# プレビューガイド切替アイコン要件

合成フォント設定のプレビューには、次の2個の独立したトグルボタンを置く。
どちらも初期状態はオンで、ダイアログを開いている間だけ状態を保持する。プロファイルへは保存せず、
字幕やテキストの出力にも影響させない。

| ボタン | 役割 | アクセント色 | ツールチップ／アクセシブル名 |
|---|---|---|---|
| ベースライン | 各文字runのベースラインを表示する | `#E04000` | `ベースラインガイドを表示` |
| 字形境界 | 各グリフの実インク境界を表示する | `#00C0C0` | `字形境界ガイドを表示` |

現行実装は、アイコンを用意するまでの識別表示として`B─`と`字□`を使用する。

## ビジュアル

- Illustrator系のツールバーと並べても違和感のない、塗りを抑えた細線アイコンにする。
- ベースラインアイコンは字形を表す中立色の`B`と、その下を横切るアクセント色の水平線で構成する。
- 字形境界アイコンは字形を表す中立色の`字`と、それを囲むアクセント色の矩形で構成する。
- 2種類の意味が色だけに依存しないよう、水平線と矩形という形状差を必ず残す。
- Adobe製品のアイコンをトレースせず、上記の一般的な幾何形状から独自に作成する。

## データ仕様

- マスターは背景なしのSVG、`viewBox="0 0 16 16"`を推奨する。
- セーフエリアは上下左右2px。主要図形を`2..14`の範囲へ収める。
- ガイド線は100%表示時に1px以上となる太さにし、水平・垂直線はデバイスピクセルへ整列させる。
- 字形部分はテーマ前景色を使用できる単色パスにし、ガイド部分だけ上表のアクセント色を使う。
- ラスター化が必要な場合は16、20、24、32pxを用意し、単純な拡大画像を使わない。
- ボタン背景、枠、影、角丸は画像へ焼き込まない。これらはWindowsのボタン状態で表現する。

## 状態

- オン：押下状態のボタン背景、アクセント線100%、字形100%。
- オフ：通常ボタン背景、アクセント線45%、字形70%。取り消し線は加えない。
- ホバー／キーボードフォーカス／無効状態はOSの標準表現を優先する。
- `Tab`でフォーカスし、`Space`で個別に切り替えられること。
- 高コントラストモードでは固定色よりシステム前景色を優先し、形状差で判別可能にする。
