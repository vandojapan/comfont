# comfont β

AviUtl2の標準テキストに、文字分類・Unicode範囲ごとのフォント、サイズ、ベースライン、字送り、縦横比率を適用するプラグインです。Rust / aviutl2-rsとLuaで実装しています。

## インストールと使い方

AviUtl2 v2.1.1以降が必要です。

1. `*.au2pkg.zip`をプレビュー画面へドラッグ＆ドロップし、AviUtl2を再起動します。
2. 「設定 → プラグイン設定 → 合成フォント (β)…」でプロファイルを編集・保存します。
3. 標準テキストへアニメーション効果「合成フォント」を追加します。
4. 「comfont::プロファイル」にプロファイル名を1行で入力します。初期値は`default`です。

原文はテキストボックスに保持し、装飾は描画時だけ適用します。anm2はaux2へ自動接続します。通常表示へ戻すには効果を無効化・削除してください。空欄・存在しない名前も通常表示になります。合成フォントは他の画像加工フィルターより前へ置いてください。

プロファイル保存後、描画時に約1秒間隔で変更を読み直します。プラグイン・スクリプト更新と新しい実フォントの登録には再起動が必要です。

## プロファイル編集

`default`の改名・削除はできません。中の分類・範囲は削除でき、全削除すると無装飾です。「適用」は編集画面とプレビューへ、「保存」はファイルへ反映します。「キャンセル」は最後の保存後の変更を破棄します。

| 項目 | 設定 |
|---|---|
| フォント | 直接入力または検索一覧から選択。空欄は変更なし |
| サイズ | %は100が等倍、pxは絶対サイズ |
| ベースライン | 正の値で文字を上へ移動 |
| 字送り | 正の値で文字間を広げる |
| 垂直・水平 | 常に%。100が等倍 |
| リガチャ | 範囲・フォントごとに有効 / 無効。初期ON、空のフォントでも有効 |

サイズ・ベースライン・字送りの単位は% / pxです。単位変更時に数値を自動換算しません。サイズ・縦横比率は正の値が必要です。

- Unicodeプリセットは343ブロックを1つの一覧で表示し、「よく使う範囲」「その他のブロック」の見出しを含めて全体をまとめてスクロールします。漢字・かな・欧文などの頻用範囲は先頭に並び、検索も全項目が対象です。選ぶと開始・終了を入力し、16進数で手動編集もできます。両端を含み、上限はU+10FFFF、端点にサロゲートは使えません。
- カスタム範囲が既存7分類より優先され、重複時は一覧の上から最初の一致を使います。空のフォントでも下位の範囲・分類へは移りません。
- ↑ / ↓は分類の表示順、同一分類の候補順、カスタム範囲の優先順を変更します。分類の境界では候補を含む分類全体を移動します。分類とカスタム範囲の間は移動しません。
- 分類内の候補は上からグリフを持つフォントを使います。分類の表示順を変えても文字種の対応は変わりません。
- 削除した分類は追加ダイアログから復元できます。旧プロファイルは読み込めますが、新しい項目を保存したファイルは旧版では読めません。

β版のフォント一覧は「名前 / 分類」「Unicode範囲」「フォント」のテーブルです。範囲が未設定の行は範囲列を空欄にし、罫線は文字領域の外に配置します。右端のチェックはリガチャ有効ON、空欄はOFFです。見出しと編集欄はLinkアイコンを使います。ホバー説明を表示し、編集欄の水平設定の下で切り替えます。Shiftで範囲選択、Ctrlで追加・解除、通常クリックで単独選択します。複数選択への適用は変更した項目だけを更新します。数値欄のホイールは通常1、Shift 0.1、Ctrl 10ずつ調整します。

フォント検索は最大5行で表示し、開くと検索欄へフォーカスします。展開方向はデスクトップの作業領域から決めます。日本語UIフォントはYu Gothic UI、アイコンはMaterial Icons / Symbolsを使用します。プレビュー本文の入力欄だけはNirmala UIを優先し、Windowsの多言語フォントへフォールバックします。UIとプレビューは操作・再描画要求に応じて更新します。

## 追加フォント

AviUtl2のアプリケーションデータ内の`compositefont/fonts`へTTF / OTF / TTC / OTCを置き、エディターで保存して再起動します。サブフォルダーも対象です。新しいファイルを`Font/compositefont`へコピーし、同名ファイルは上書きしません。

通常は`C:\ProgramData\aviutl2\compositefont`、ポータブル構成では本体横の`data/compositefont`にプロファイルと追加フォントを保存します。

## 対応範囲と移行

文字列全体をDirectWriteで組み、合字・結合記号・カーニング・双方向表示を扱います。言語範囲による除外はありません。対応する文字組みはWindowsと選択フォントに依存します。描画用文字列だけをNFC正規化し、保存本文は変更しません。設定画面のプレビューも同じ描画エンジンを使い、ガイドはシアンが描画後のグリフ境界、マゼンタがフォントのアセント・ディセントと字送りに基づく字枠、赤がベースラインです。合字は1つのグリフとして囲み、空白には字枠だけを表示します。

設定画面の「リガチャ / 有効」は初期ONです。OFFで対象範囲を強制解除し、プレビューとanm2表示へ反映します。旧設定も同じ描画を維持してチェック表示を反転します。anm2の「リガチャを強制解除」（初期値OFF）をONにすると、範囲別設定にかかわらず全体に適用し、描画用文字列だけで任意・必須の結合を抑止します。接続形・結合記号・カーニング・字間も変わります。単一文字として入力した合字は分解しません。OFFに戻すと通常の字形形成へ戻ります。

範囲・分類は元の書記素（基底文字と結合記号など）の先頭文字で判定し、フォント・補正をまとまり全体に適用します。候補フォントは正規化後のまとまり全体の字形で判定します。結合記号だけの別範囲を登録しても、まとまりの途中へ装飾タグは挿入しません。

対象は横書き・標準文字装飾・静止本文です。縦書き、影・縁取り・取り消し線、表示速度、個別文字、スクロール、Lua本文、未対応タグ、カラーフォント、処理失敗時は元の表示を維持します。ホストとの完全一致は保証しません。本文・生成文字列は64 KiB、サイズは1～512、画像は4096×4096までです。

旧プルダウン指定のオブジェクトはプロファイル名を入力し直してください。旧本文ラッパーは、テキスト欄の「プラグイン → 合成フォント → 元の本文に戻す」で解除できます。暫定objectは同梱しません。

## 開発・資料

設定画面はeguiに一本化しました。通常ビルド・Releaseともにβ版の画面を使用します。

```powershell
cargo fmt --all -- --check
cargo test --workspace --all-features --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
cargo build -p compositefont-editor-plugin --release
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-beta.ps1
```
