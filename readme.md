# comfont 0.3.1 β

AviUtl2の標準テキストに、文字分類・Unicode範囲ごとのフォントや文字補正を適用するプラグインです。原文は保持し、描画時に装飾します。

## 導入・使い方

**AviUtl2 v2.1.1以降**が必要です。

1. `*.au2pkg.zip`をプレビュー画面へドラッグ＆ドロップし、再起動します。
2. 「設定 → プラグイン設定 → 合成フォント (β)…」でプロファイルを編集・保存します。
3. 標準テキストにアニメーション効果「描画@comfont」を追加します。
4. 「comfont::プロファイル」に名前を入力します。初期値は`default`です。

aux2への接続は自動です。「描画@comfont」は本文を生成するスクリプト制御の後、他の画像加工フィルターの前に置いてください。効果の無効化・削除、名前の空欄・不一致で通常表示へ戻ります。

保存したプロファイルは描画時に約1秒間隔で更新されます。プラグイン・スクリプトの更新と追加フォントの登録後は再起動してください。

PSDToolKitの字幕には同梱の「合成フォント字幕.object」を使います。本文内の`settings.id`にキャラクターIDまたはレイヤー指定を設定し、プロファイルは後段の「描画@comfont」効果で指定します。PSDToolKitは別途必要です。

### パイプでの収集

「パイプ@comfont」は設定欄のない収集・受け渡し専用の効果です。原文または明示連携済みの生成本文をaux2へ渡します。本文の加工・Luaの再実行・変数名の設定は行いません。

```text
テキスト → スクリプト制御（使用時） → パイプ@comfont → 描画@comfont
```

公開APIからスクリプト制御の実行後本文やローカル変数を取得することはできません。生成本文には下記の連携が必要です。別オブジェクトの値が混入するため、共有グローバルの`text`を無条件には収集しません。通常の原文はコードなしで収集できます。

### スクリプト制御との連携

スクリプト制御で生成した本文にも装飾を適用するには、本文の加工が完了した位置へ次の共通スニペットを追加してください。`text`は、ご自身のスクリプトで使っている本文変数に置き換えます。

```lua
local cf = obj.module("compositefont")
cf.capture_text(text, tostring(obj.id), obj.frame,
    obj.getvalue("テキスト", "テキスト"),
    obj.getvalue("スクリプト制御", "スクリプト"))
```

「パイプ@comfont」「描画@comfont」はスクリプト制御の後に配置します。本文がない場合も空文字を渡し、複数の文字列を表示する場合は本文全体を結合して渡してください。既存の通常描画処理はそのまま使います。原文や生成した制御文字は本文欄へ書き戻しません。標準テキスト本文内のLuaでは最後の引数を省略します。[複数のスクリプト制御を使う場合などの詳細](docs/lua-api.md#生成本文の連携)。

## プロファイル編集

「適用」で一覧・プレビューへ、「保存」でファイルへ反映します。「キャンセル」は未保存の変更を破棄します。

| 項目 | 設定 |
|---|---|
| フォント | 直接入力・検索で選択。空欄は変更なし |
| サイズ | % / px。100%が等倍 |
| ベースライン | % / px。正の値で上へ移動 |
| 字送り | % / px。正の値で文字間を広げる |
| 垂直・水平 | 100%が等倍 |
| リガチャ | 初期ON。OFFで対象範囲の結合を強制解除 |

単位の変更時に数値は換算しません。サイズ・縦横比率には正の値を指定します。

- 範囲はUnicodeプリセットから選択、または開始・終了を16進数で入力します。プリセットは名前・コードポイントで検索できます。
- カスタム範囲を優先し、重複は一覧の上から最初の一致を使います。分類内の候補フォントも上から字形の有無で選びます。
- ↑ / ↓で分類・候補の順序やカスタム範囲の優先順位を変更します。
- Shiftで範囲選択、Ctrlで追加・解除、通常クリックで単独選択します。一括適用は変更した項目だけを更新します。
- 数値欄はホイールで調整できます（通常1 / Shift 0.1 / Ctrl 10）。
- `default`は改名・削除できません。中の分類・範囲はすべて削除でき、空なら無装飾です。削除した分類は追加ダイアログで復元できます。

表の✔はリガチャ有効、空欄は無効です。anm2の「リガチャを強制解除」は全範囲に適用します。解除すると接続形や字間も変わるため、通常の多言語表示では初期値OFFを使います。

プレビューのガイドは、シアンがグリフの実寸、マゼンタが字枠、赤がベースラインです。

## 追加フォント

アプリケーションデータ内の`compositefont/fonts`へTTF / OTF / TTC / OTCを置き、設定画面で保存して再起動します。サブフォルダーも対象です。同名の登録済みファイルは上書きしません。

保存先は通常`C:\ProgramData\aviutl2\compositefont`、ポータブル構成では本体横の`data/compositefont`です。

## 対応範囲・互換性

横書きの静止本文が対象です。多言語の合字・結合記号・双方向表示をDirectWriteで処理し、プレビューも同じ描画を使います。文字組みはWindowsと使用フォントに依存します。

縦書き、影・縁取り、表示速度、個別文字、スクロール、未連携のLua本文、未対応タグ、カラーフォントなどは元の表示を維持します。詳細な制限は[anm2仕様](docs/anm2-spec.md)を参照してください。

0.3.1では旧「合成フォント.anm2」を同梱しません。旧効果を使うオブジェクトは「描画@comfont」へ置き換え、プロファイルを指定してください。

旧プロファイルは読み込めます。新しい項目を保存したファイルは旧版では読めません。旧プルダウン指定は名前を入力し直してください。旧本文ラッパーはテキスト欄の「プラグイン → 合成フォント → 元の本文に戻す」で解除できます。

```powershell
cargo build -p compositefont-editor-plugin --release
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-beta.ps1
```
