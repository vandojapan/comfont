# comfont 0.3.2 β

AviUtl2のテキストに、文字の種類やUnicode範囲ごとに異なるフォント・サイズ・字間などを適用するプラグインです。通常のテキストは本文を変更せず、AviUtl2標準の描画で表示します。

## 導入と基本的な使い方

AviUtl2 **v2.1.14以降**が必要です。

1. 配布パッケージ（`*.au2pkg.zip`）をAviUtl2のプレビュー画面へドラッグ＆ドロップし、AviUtl2を再起動します。
2. 「設定 → プラグイン設定 → 合成フォント (β)…」を開き、`default` を編集するか、新しいプロファイルを作って「保存」を押します。
3. 通常のテキストオブジェクトにアニメーション効果「描画@comfont」を追加します。
4. 効果の「comfont::プロファイル」に、保存したプロファイル名を入力します。初期値は `default` です。

設定画面の「適用」は編集内容をプレビューに反映します。動画へ反映するには「保存」または「保存して閉じる」を押してください。保存した設定は描画時に約1秒間隔で読み直されます。

## プロファイルの設定

「追加」から文字分類・Unicodeプリセットを選ぶか、開始・終了コードポイントを16進数で入力して範囲を作れます。プリセットは名前やコードポイントで検索できます。範囲が重なる場合はカスタム範囲を優先し、同じ条件では一覧で先にある設定を使います。フォント候補は上から順に字形の有無を調べます。

| 項目 | 設定内容 |
|---|---|
| フォント | 名前を入力するか、検索して選択。候補名は各書体で表示します。空欄なら変更しません。 |
| サイズ | `%` または `px`。100%が等倍です。 |
| ベースライン | `%` または `px`。正の値で上へ移動します。 |
| 字送り | `%` または `px`。正の値で文字間を広げます。 |
| 垂直・水平 | 100%が等倍です。 |
| リガチャ | プロファイル内の設定は設定画面のプレビュー専用です。既定はONです。 |

各項目の白い目はComfontによる上書きが有効、灰色の斜線付きの目は無効です。無効にしても入力値は保存され、再び有効にすると戻ります。色・太字・斜体・縁取りはComfontから上書きしません。

- ↑ / ↓で分類とカスタム範囲を並べ替えられます。Shiftで連続選択、Ctrlで追加・解除、通常クリックで単独選択します。複数行への「適用」は変更した項目だけを更新します。
- 数値はホイールでも変更できます（通常1、Shiftで0.1、Ctrlで10）。単位を変えても数値は自動換算されません。
- `default` は改名・削除できません。中の範囲はすべて削除でき、空のプロファイルでは装飾しません。
- プレビューのガイドは、シアンがグリフ境界、マゼンタが字枠、赤がベースラインです。プレビューは設定確認用で、動画の描画には使いません。

## 特殊な本文と制限

「描画@comfont」が自動で装飾するのは、**標準テキスト入力が1つで、本文にLuaや未対応の制御タグがないテキストオブジェクト**です。該当しない本文、存在しないプロファイル、効果が無効な場合は通常表示になります。本文に生成した装飾文字列を書き戻すことはありません。

本文内のLuaで文字列を生成している場合は、出力直前に[4行の連携コード](docs/lua-api.md#標準テキスト向けの装飾)を追加できます。同梱ファイルは `Plugin/comfont-snippets/decorate-text.lua` です。「パイプ@comfont」は文字列の収集用で、追加するだけでは描画済みの文字を装飾できません。

PSDToolKitの字幕には同梱の「合成フォント字幕.object」を使用します。本文内の `settings.id` にキャラクターIDまたは `L3` などのレイヤー指定を設定し、「描画@comfont」でプロファイルを選びます。PSDToolKitは別途必要です。

## 動画出力でのリガチャ

| 「リガチャを強制ON」 | 動画出力の挙動 |
|---|---|
| OFF（初期値） | AviUtl2の標準描画を使います。合字はAviUtl2とフォントに従い、プロファイル内のリガチャ設定やアンチエイリアス欄では切り替えられません。 |
| ON（試験機能） | **テキストオブジェクト全体**をComfontのDirectWrite経路で組版し、対応フォントへ任意の合字機能を要求します。プロファイル内のリガチャ設定はこの経路では上書きされます。 |

ONでも、フォントに該当する合字がなければ合字の形は変わりません。ただし、画像化による描画差は生じ得ます。異なるフォント・書式に分かれた文字をまたぐ合字は保証しません。保存本文は変更せず、ZWNJも挿入しません。

ONが使えるのは、Luaを含まない静的な標準テキストで、文字装飾が「標準文字」、表示速度が0の場合です。縁取り・影、文字ごとの個別オブジェクト、自動スクロール、移動座標上の表示、未対応の制御タグ、カラーフォントには対応しません。フォント解決や描画に失敗した場合も**標準描画へ戻るため、強制ONでも合字が適用されないことがあります**。本文は64 KiBまで、文字サイズは1～4096、生成画像は一辺8192ピクセルかつ1677万画素までです。

ONの間だけ「アンチエイリアス」を選べます。「標準」は横方向、「滑らか」は縦横方向に平滑化し、「なし」は平滑化を止めます。大きな文字では前二者の差は輪郭付近に限られます。**ONでは描画結果を一度画像として渡すため、標準描画と輪郭・位置・字間が異なる場合があります。** 品質を優先する作品ではOFFを基本に、必要なオブジェクトで比較してください。

装飾が反映されないときは、プロファイルを「保存」したか、効果に入力した名前が一致しているか、本文が上記の対象条件を満たすかを確認してください。追加したフォントが候補に出ない場合はAviUtl2を再起動してください。

## 保存先と更新時の注意

プロファイルは通常 `C:\ProgramData\aviutl2\compositefont\profiles.json` に保存します。ポータブル構成ではAviUtl2本体横の `data/compositefont/profiles.json` です。追加フォントは同じ `compositefont` フォルダーの `fonts` にTTF / OTF / TTC / OTCファイルを置き、設定画面で保存してAviUtl2を再起動します。プラグインやスクリプトを更新した場合も再起動してください。

旧プロファイルは読み込めます。旧形式にない上書き有効・無効の設定はONとして扱い、値を維持します。新形式で保存した設定は旧版では読めません。旧「合成フォント.anm2」と検証用オブジェクトは配布していません。以前の版で本文がLuaラッパーに置き換わっている場合は、本文欄の「合成フォント → 元の本文に戻す」を選んで復元できます。
