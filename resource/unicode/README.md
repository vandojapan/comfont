# Unicodeプリセット

Unicode 17.0.0 の公式 [Blocks.txt](https://www.unicode.org/Public/17.0.0/ucd/Blocks.txt) を使用しています。
原本をこのフォルダーに保存し、Rust定数を `crates/core/src/unicode_presets.rs` に収録しています。

346ブロックのうち、Unicodeスカラー値ではないサロゲート専用3ブロックを除く343ブロックを登録します。
漢字・ひらがな・カタカナ・Basic Latin・半角／全角の5ブロックと「絵文字（Unicode 18.0）」を先頭に置き、残りは開始コードポイント順です（全344プリセット）。
よく使うブロックと主要な文字体系には日本語名を付けています。検索には公式英語名も使用できます。
既存プロファイルにはブロックの番号ではなく範囲と名前を保存しているため、一覧の変更で設定は変わりません。

## 絵文字（Unicode 18.0）

Unicode.orgの公式 [emoji-data.txt](https://www.unicode.org/Public/18.0.0/ucd/emoji/emoji-data.txt) の `Emoji` と `Emoji_Component` の和集合を使います。対象の1,546コードポイントを、隣接部分を統合した154個の範囲として `crates/core/src/emoji_ranges.rs` に収録しています。原本は [emoji-data-18.0.0.txt](emoji-data-18.0.0.txt) です。

顔・動物・食べ物・乗り物だけでなく、ハート・天気記号・国旗の地域指示記号・肌色・髪型・キーキャップ・ZWJ・VS16・タグ文字を含みます。開始・終了の外枠はU+0023～U+E007Fですが、その間全体には適用せず、公式データにある154範囲だけを対象とします。設定画面の「対象コードポイントを表示」で全範囲を確認できます。

数字 `0`～`9`、`#`、`*` も公式の絵文字属性に含まれますが、設定の適用時には `1️⃣` のようなキーキャップの構成だけを対象とします。単独の数字・`#`・`*` は絵文字行を通過し、下位の一致する範囲または数字・記号の分類へ渡します。キーキャップの構成文字にフォント候補が対応しない場合も、書記素全体を下位の設定へ渡します。`©`・`®` などは単独でも引き続き対象です。範囲に含まれることはフォントの字形対応を保証しません。

この資料はプリセットの対象集合を定義するものです。設定プレビュー・映像出力の対応形式、国旗などの合成字形、キーキャップの判定とSVG変換の条件は[絵文字の設定と制約](../../docs/emoji.md)を参照してください。公式の対象集合は保持したまま、キーキャップには構成を判定して設定を適用します。

プリセットを追加すると154範囲を1行の設定として保存し、名前を変更したりコピーしたりしても対象集合を維持します。単一範囲の開始・終了編集はできません。以前の「絵文字（主要範囲）」を保存済みの場合は、削除して新プリセットを追加してください。

テストでは `Emoji` / `Emoji_Component` と収録範囲の完全一致、および公式 [emoji-test.txt](https://www.unicode.org/Public/18.0.0/emoji/emoji-test.txt) に載る全シーケンスの構成文字が対象内であることを検証します。検証用原本は [emoji-test-18.0.0.txt](emoji-test-18.0.0.txt) です。
